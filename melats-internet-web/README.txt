Melat's Internet - website

Upload this whole folder (index.html must stay at the top level) to any static host.

Easiest: Netlify Drop
1. Go to https://app.netlify.com/drop
2. Drag this folder onto the page.
3. You get a link like https://something.netlify.app
4. Optional: Site settings -> Change site name, e.g. melats-internet.netlify.app

On her iPhone: open the link in Safari -> Share -> Add to Home Screen.
It gets its own icon and opens full screen like an app.

The game remembers progress on each phone. After testing on a phone,
tap "Start over from the beginning" on the locks page.
